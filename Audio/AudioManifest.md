Leave *Normalize* and *Force To Mono* off for all clips: the loudness matching is baked into the files, and Unity's Normalize (applied during Force To Mono) re-peaks each clip. When this manifest was written, `Game/Assets/Editor/ProjectSetup.cs` was importing Voice with `forceToMono: 1` + `normalize: 1`. That will undo the -18 LUFS matching between lines and should be switched off. Ambience and music loops loop gaplessly (decoded sample counts equal the loop length). Set `AudioSource.loop = true` for every clip marked loop.

### Transcription check (pronunciation)

`npx --no-install hyperframes transcribe --help` works, but no ASR runtime is installed for it on this machine (`--no-runtime-install` returned `whisper_unavailable`). Its whisper.cpp path needs cmake to build, and Parakeet is not installed. So the check used the **faster-whisper** package already in the system Python with Whisper models already in the local Hugging Face cache (`small.en`, the same model family Hyperframes defaults to, plus `large-v3` as a second opinion), offline. Phonemes were also inspected with Kokoro's own front-end (`kokoro_onnx.tokenizer.Tokenizer().phonemize`).

**Fixed during generation** (wrong reading found, TTS input respelled, re-verified):
